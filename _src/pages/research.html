Research

Research focus

Securing machines that move, and deciding where their computation should run.

UAV / drone technology

Secure communications in UAVs, authentication protocols, and long-range communication for drones.

  • Drone Remote ID authentication compliant with ASTM standards
  • Public-key infrastructure for broadcast Remote ID
  • Optimal placement of ground observers for continuous drone monitoring

Fog / edge computing

Making distributed computation feasible on constrained, mobile infrastructure.

  • Edge intelligence and programmable edge networks
  • Computation offloading on resource-constrained devices
  • Verifiable computation and mobility-aware task migration

Long-range, scalable IoT

Long-range and scalable Internet of Things networks using Wi-Fi HaLow.

  • IEEE 802.11ah PHY and MAC features for next-generation IoT
  • Scalable architectures for thousands of stations per access point
  • Internet-of-Drones architectures over sub-1 GHz links

My research at C2PS focused on the design and implementation of lightweight and context-aware authentication protocols for drone Remote ID, addressing critical security challenges in compliance with ASTM standards for UAV airspace. I am also working on context-aware drone Remote ID authentication and optimised observer placement for securing the airspace for drones. For more details about these projects, please visit the Secure UTM Systems Lab.
